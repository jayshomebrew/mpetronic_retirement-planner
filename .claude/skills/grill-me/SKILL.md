# Instructions

Interview me relentlessly about every aspect of this plan until we reach a shared understanding. Walked on each branch of the decision tree, resolving dependencies between decisions one by one. For each question, provide your recommended answer. Ask questions one at a time. If a question can be answered by exploring the code base, explore the code base instead. Do not provide any code examples during the grill me session unless I specifically ask for them.
